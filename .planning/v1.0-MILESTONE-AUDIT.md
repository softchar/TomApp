### Partial Connection (WARNING)

**AlertSettingsProvider not injected into ReboundAlertService from Dashboard**

- **Location:** `lib/screens/rebound_dashboard_screen.dart` line 66-70
- **Issue:** `ReboundAlertService` constructed without passing `alertSettings` parameter
- **Impact:** User-configured thresholds from ProfileScreen settings UI are persisted but never reach live monitoring pipeline. Default thresholds (75/50) used instead.
- **Affected Requirements:** ALERT-01, ALERT-04
- **Fix:** Read `AlertSettingsProvider` from context in `_startAlertService()` and pass to constructor
