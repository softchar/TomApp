<task type="auto">
  <name>Task 2: macd_chart_widget.dart 迁移到 fl_chart 1.2 API</name>
  <files>lib/widgets/macd_chart_widget.dart</files>
  <action>
将 `lib/widgets/macd_chart_widget.dart` 中所有 fl_chart 0.65 API 调用迁移到 fl_chart 1.2 API。核心映射关系（fl_chart 1.0 官方 breaking change ——注意：0.65 的 `Fl` 前缀类型几乎全部移除或重命名）：

**类型重命名（0.65 → 1.2）：**
- `FlGridData(show: ...)` → `GridData(show: ...)`
- `FlBorderData(show: ...)` → `BorderData(show: ...)`
- `FlTitlesData(show: ...)` → `TitlesData(show: ...)`
- `FlLine(...)` → `FlLine(...)` 保留（1.x 中仍叫 `FlLine`）

**LineChartBarData 字段变更（0.65 → 1.2）：**
- `isCurved: true` → 移除，替换为 `curveSmoothness: 0.35`（0.35 为默认平滑值，保持原弯曲效果）
- `barWidth: 2` → 保留不变
- `isStrokeCapRound: true` → 保留不变
- `dotData: FlDotData(show: false)` → 保留不变
- `belowBarData: BarAreaData(show: false)` → 该字段从 LineChartBarData 中移除。fl_chart 1.x 中，线图下方的区域填充改为通过 `belowBarData` 或完全移除。当前代码设为 `show: false`（即不显示区域）——直接删除该行即可。如有编译器错误指向 `belowBarData`，改为 `areaData: null` 或直接删除。

**BarChartData / BarChartRodData 字段变更（0.65 → 1.2）：**
- `gridData: FlGridData(...)` → `gridData: GridData(...)`（类型跟随上述重命名）
- `titlesData: FlTitlesData(...)` → `titlesData: TitlesData(...)`
- `borderData: FlBorderData(...)` → `borderData: BorderData(...)`
- `barGroups: ...` → 保留不变
- `BarChartRodData(toY: ..., color: ..., width: 4)` → 保留不变

**迁移执行步骤：**
1. 用项目级搜索替换：`FlGridData` → `GridData`, `FlBorderData` → `BorderData`, `FlTitlesData` → `TitlesData`
2. 手动处理 `isCurved: true` → `curveSmoothness: 0.35`
3. 手动处理 `belowBarData` — 删除该行或改成注释
4. 运行 `flutter analyze lib/widgets/macd_chart_widget.dart` 检查残留编译错误
5. 如有其他 fl_chart 编译错误，对照 fl_chart 1.2 的 `BarChartData`/`LineChartData` 构造函数签名修正（IDE 自动补全或 fl_chart 源码 inline doc 提供字段名）
6. 最终确认 `flutter analyze` 全项目 0 错误

**保持不变的逻辑：**
- `_buildBarChartData` 的 BarChartGroupData / BarChartRodData 数据组装逻辑不变
- `_buildLineChartData` 的 FlSpot 列表构建不变
- MACD 正负值着色逻辑（macd>=0 红、macd<0 绿）不变
- DIF 线蓝色 / DEA 线橙色不变
- 图例（_buildLegend）不变

**零回归标准：** 迁移后的 widget 在使用处编译通过即可——视觉验证由 checkpoint 覆盖。不要引入任何新功能或行为变更。
