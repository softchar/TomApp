# 快速开始

## API Key 权限设置

- 新创建的API的默认权限是`只读`。
- 如果需要通过API提款, 需要在UI修改权限, 选中 `允许提现`。
- 如果需要通过API交易, 需要在UI修改权限, 选中对应交易权限

## 账户

### 现货账户

新注册的币安账号都会有一个现货(SPOT)账号。

### 期货账户

为了开设期货(FUTURES)账户, 可以参考币安期权介绍

### 期货测试网

用户可以使用期货的测试网来体验FUTURES交易. 现在只能通过API来交易。更多信息请参考期货测试网。

### 期权账户

为了开设期权(OPTION)账户, 可以参考Binance期权概览
