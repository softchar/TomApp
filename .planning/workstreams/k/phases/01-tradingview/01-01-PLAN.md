**createChart 配置修改：**
1. `rightPriceScale.scaleMargins`: `{ top: 0.05, bottom: 0.2 }` → `{ top: 0.05, bottom: 0.15 }`（D-05：成交量占底部15%）
2. `timeScale.rightOffset`: `0` → `5`（D-10：右侧留白5根蜡烛）

**成交量系列配置修改：**
7. 成交量 `scaleMargins`: `{ top: 0.8, bottom: 0 }` → `{ top: 0.85, bottom: 0 }`（D-05：配合15%底部占比）

**成交量颜色修正（D-06）：**
8. 在 `_buildChartData()` 方法中，成交量颜色逻辑当前为涨红跌绿（中国习惯），需改为涨绿跌红（国际习惯）：
   - `e.value.close >= e.value.open` 时颜色从 `'rgba(239, 83, 80, 0.5)'` 改为 `'rgba(38, 166, 154, 0.5)'`（涨=绿）
   - `e.value.close < e.value.open` 时颜色从 `'rgba(38, 166, 154, 0.5)'` 改为 `'rgba(239, 83, 80, 0.5)'`（跌=红）

**updateChart() 可见范围逻辑修改（D-08/D-09）：**
9. `visibleCount` 从 `30` 改为 `50`（D-09：初始显示50根蜡烛）
10. 可见范围逻辑从"从索引0开始显示"改为"最新数据在右侧"：
    - 当前逻辑：`from: -0.5, to: visibleCount - 0.5`（从左侧开始）
    - 目标逻辑：`from: candleCount - visibleCount - 0.5, to: candleCount - 0.5`（最新数据在右侧，per D-08）
11. `updateChart()` 中 `barSpacing` 从 `8` 改为 `6`，`rightOffset` 从 `0` 改为 `5`

**中文本地化（D-18~D-21）：**
12. 在 `createChart` 配置中添加 `localization` 字段（per D-18）：
    - `locale: 'zh-CN'`
    - `timeFormatter`: 函数接收 Unix 时间戳（秒），返回 `MM-dd HH:mm` 格式（D-16/D-19）
    - `priceFormatter`: 函数接收价格，返回 `toLocaleString('zh-CN', { minimumFractionDigits: 2, maximumFractionDigits: 2 })` 格式（D-20）

注意：蜡烛颜色（涨红跌绿）保持不变，这是中国习惯。只有成交量颜色改为涨绿跌红（国际习惯，D-06）。下跌段/回拉段高亮标记功能必须保留。
