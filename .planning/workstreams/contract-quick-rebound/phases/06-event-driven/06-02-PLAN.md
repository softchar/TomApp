创建 `BacktestEngine` 和 `TradeSimulator` 两个类，按 RESEARCH.md 模式 1 event-driven 架构实现：

**BacktestEngine** (`lib/services/rebound/backtest_engine.dart`)：

1. **构造器**：`BacktestEngine({required ReboundDetector detector, required TradeSimulator tradeSimulator, required AppDatabase db})`。持有 detector/tradeSimulator/db 三个依赖。

2. **`Future<BacktestReport> runBacktest({required String symbol, required String interval, required ReboundParams params, required BacktestConfig config})`**：
   - 从 drift Klines 表读取 `symbol + interval` 的历史 K 线，按 `openTime` 升序排列。
   - 逐 bar 遍历 `for (int i = 0; i < klines.length; i++)`，当前 bar = `klines[i]`。
   - **收盘阶段**（每根 bar 处理后）：
     - 若 `position != null`：调用 `tradeSimulator.checkStopLoss(position, bar)`、`tradeSimulator.checkTakeProfit(position, bar)`、`tradeSimulator.checkTimeExit(position, bar, i, klines.length)`。
     - 若 `position != null` 且 bar.time 跨越 **00:00/08:00/16:00 UTC** 整点：调用 `tradeSimulator.applyFundingFee(position, bar.time, fundingRateService)` 扣除资金费。
     - 构造 `rollingWindow = klines.sublist(0, i + 1)`（只用 bar[0..i] 不含未来数据），调用 `detector.evaluate(rollingWindow, params, symbol: symbol, timeframe: interval)`。
     - 保存 signal 供下一根开盘使用。
   - **开盘阶段**（下根 bar 处理前）：若上一根触发了 signal 且 `position == null` 且 `i + 1 < klines.length`，调用 `tradeSimulator.enterPosition(signal, klines[i + 1])`，记录 `BacktestTrade`（entryTime=klines[i+1].time, entryPrice=klines[i+1].open）。
   - 遍历完成后若有未平仓位：在最后一根 bar 的 close 市价平仓。
   - 返回 `List<BacktestTrade>`。

3. **禁止事项**（PITFALLS.md Pitfall 1 硬约束）：
   - **永不使用 vectorized/df.shift() 操作**——所有计算走逐 bar for 循环。
   - **detector.evaluate 的 window 参数只含 bar[0..i]**，不含 bar[i+1] 及之后任何一根。
   - **Bar[i] 的 close 不在 bar[i] 的决策中使用**——bar[i] 收盘触发 signal，bar[i+1] 开盘才进场。

**TradeSimulator** (`lib/services/rebound/trade_simulator.dart`)：

4. **`Position enterPosition(ReboundSignal signal, KlineData entryBar)`** (D-01/D-02/D-03)：
   - entryPrice = `entryBar.open`（bar[t+1].open，非 signal.entryPrice）。
   - stopLoss = `signal.swingLowPrice - 0.3 * atr`。ATR 从 Phase 1 TechnicalIndicators.atr 计算（用 signal 触发前 14 根 K 线）。
   - takeProfit1 = `signal.swingHighPrice - (signal.swingHighPrice - signal.swingLowPrice) * 0.618` = 61.8% Fib 回撤位。
   - takeProfit2 = `signal.swingHighPrice` = 100% Fib 回撤位。
   - 返回 Position(symbol:, entryTime:, entryPrice:, stopLoss:, takeProfit1:, takeProfit2:, exitedHalf: false)。

5. **`Position? checkStopLoss(Position position, KlineData bar)`** (D-02)：若 `bar.low <= position.stopLoss` → 以 stopLoss 价格退出（滑点不利方向已含在模型中），记录 exitReason="stopLoss"，返回 null（仓位已平）。

6. **`({Position? position, String? exitType})? checkTakeProfit(Position position, KlineData bar)`** (D-03)：
   - 若 !position.exitedHalf 且 `bar.high >= position.takeProfit1`：卖出 50% 仓位（实现为记录 pnl = 0.5 * (takeProfit1 - entryPrice) / (entryPrice - stopLoss) R 倍数），position copyWith(exitedHalf=true)。继续持有剩余 50%。
   - 若 position.exitedHalf 且 `bar.high >= position.takeProfit2`：卖出剩余 50%，记录 exitType="takeProfit2"，返回 null。
   - 若同一根 bar 同时触发 TP1 和 TP2：先 TP1 再 TP2（两个独立事件）。

7. **`Position? checkTimeExit(Position position, KlineData bar, int barIndex, int totalBars)`** (D-04)：
   - 持仓 K 线数 = `barIndex - entryBarIndex`。若 `>= config.maxHoldBars`（默认 20 根），在下一根 bar.open 市价退出。
   - exitReason="timeExit"。

8. **`double applyTransactionCost(double pnlR, double entryPrice, double exitPrice)`** (D-06)：
   - 进场 taker fee = `entryPrice * 0.0006`（0.06%）。
   - 出场 taker fee（两次 TP 或单次退出各算一次）= `exitPrice * 0.0006`。
   - 滑点 = `entryPrice * 0.001` + `exitPrice * 0.001`（0.1% 单边）。
   - 总成本从 R 倍数中扣除。

9. **`double applyFundingFee(Position position, DateTime barTime, FundingRateService fundingRate)`** (D-05)：
   - 检查 barTime 是否跨越 00:00/08:00/16:00 UTC。若跨越，从 `fundingRate.getRate(position.symbol, settlementTime)` 获取该结算时刻的 funding rate。
   - fundingCost = `position.quantity * fundingRate`（名义仓位价值 × rate）。
   - 从 pnl（R 倍数）中扣除。

创建 `WalkForward` 和 `ReportGenerator` 两个类：

**WalkForward** (`lib/services/rebound/walk_forward.dart`)：

1. **`class FoldResult`**：数据类，字段 foldIndex(int)、trainMonths(int 起始月, int 结束月)、testMonth(int)、bestParams(ReboundParams?)、testTrades(List&lt;BacktestTrade&gt;)、testStats(BacktestReport?)。

2. **`Future<List<FoldResult>> runWalkForward({required List<KlineData> allKlines, required List<ReboundParams> paramGrid, required BacktestEngine engine, required BacktestConfig config})`**：
   - 将 `allKlines` 按月份分桶（以第一个 data point 的月份为 month 1，依次递增）。假设 6 个月数据。
   - **Fold 0**：train 月 1-3，test 月 4。每个 paramGrid 组合：在 train+test 完整数据上跑一次（对于 fold 0 是月 1-4 的所有 K 线），但只记录 test month 4 内产生的 trades。
   - **Fold 1**：train 月 1-4，test 月 5。
   - **Fold 2**：train 月 1-5，test 月 6。
   - 对于每个 fold，320 个参数组合串行执行。每个组合调用 `engine.runBacktest(symbol:, interval:, params: gridCombination, config:)`。
   - 对每个 fold，找出 out-of-sample 上 `totalPnL` 最高的参数组合记为 bestParams。
   - 返回 `List<FoldResult>`（共 3 个元素）。

3. **`List<ReboundParams> buildParamGrid()`** (D-12)：构造 320 个 ReboundParams 实例的列表。四维扫描：

   - **D-13 强制：评分权重（30/30/25/15）不进扫描——沿用默认值。**
   - **D-14 强制：共振过滤器开关不进扫描——全部保持默认 true。**

4. **`BacktestReport aggregateOutOfSample(List<FoldResult> folds, BacktestConfig config)`**：提取所有 fold 的 testTrades 合并为一个大厅列表，调用 `ReportGenerator.generate(config, allTestTrades)` 生成聚合报告。

**ReportGenerator** (`lib/services/rebound/report_generator.dart`)：

5. **`BacktestReport generate({required BacktestConfig config, required List<BacktestTrade> trades})`**：
   - `winRate` = winning trades / total trades（PnL > 0 视为赢）。
   - `avgR` = sum(rMultiple) / totalTrades。
   - `profitFactor` = sum(positive pnl) / abs(sum(negative pnl))。无亏损时 = double.infinity。
   - `maxDrawdown`：遍历累计权益曲线，跟踪 runningMax，计算每个点的 drawdown = (runningMax - cumulativePnL) / runningMax，取最大值。
   - `sampleCount` = trades.length。
   - `totalPnL` = sum(pnl)。
   - `avgRPerTrade` = totalPnL / totalTrades。
   - `equityCurveZeroCost`：按交易顺序累计纯 R 倍数（rMultiple），输出 (tradeIndex, cumulativeR) 列表。
   - `equityCurveWithCost`：按交易顺序累计含成本 PnL（pnl），输出 (tradeIndex, cumulativeR) 列表。

6. **权益曲线生成等式**：
