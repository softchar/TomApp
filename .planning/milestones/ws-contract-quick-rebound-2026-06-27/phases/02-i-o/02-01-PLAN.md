**三阶段管线实现**（per D-02）：

Stage 1 — 下跌段检测 `_detectDropLeg()`：
- 从 window 末尾向前扫描，找 swing low（用 `_ti.swingLow(window, lookback: params.swingLookback)`）
- 找到 swing low 索引 `lowIdx` 后，向前找对应的 swing high（下跌起始点）
- 计算跌幅 = `swingHigh - swingLow`
- 验证跌幅 ≥ `params.dropAtrMultiplier × ATR`（`_ti.atr(window, period: params.atrPeriod)`）
- 验证跌幅发生在 ≤ `params.dropMaxCandles` 根 K 线内
- 验证跌幅 ≥ 对应周期的 % 兜底阈值（根据 timeframe 参数选择）
- 返回 `(startIndex, endIndex, dropMagnitude)` 或 null

Stage 2 — 拉回段检测 `_detectRecoveryLeg()`：
- 从 swing low 之后扫描，找价格回补
- 计算回补比例 = `(当前close - swingLow) / (swingHigh - swingLow)`
- 验证回补比例 ≥ `params.recoveryMinRatio`（默认 0.5）
- 验证回补在 ≤ `params.recoveryMaxCandles` 根内完成
- 验证收盘价站上跌幅中点（`midpoint = (swingHigh + swingLow) / 2`）
- 返回 `(recoveryEndIndex, recoveryRatio, speed)` 或 null

Stage 3 — 共振过滤 `_checkConfluence()`：
- RSI 超卖拐头：`_ti.rsiTurningUp(window, period: params.rsiPeriod, oversold: params.rsiOversold)` 返回 `.oversoldTurningUp == true`
- 放量确认：拉回段平均成交量 / 下跌段平均成交量 ≥ `params.volumeMultiplier`
- 支撑位：swing low 附近（±1%）有前期支撑（`_ti.swingLow` 在更早位置）
- K 线形态：确认 K 线有长下影线（`(close - low) / (high - low) > 0.6` 且实体较小）
- 返回 `Set<ConfluenceType>`（通过的过滤器集合）

**评分逻辑**（per D-04, SCORE-01）：

`_calculateScore()` 内部方法，权重业务先验固定（标记「Phase 6 校准」）：
- recoveryRatio 权重 30：50%→15, 61.8%→22, 100%→30（线性插值）
- recoverySpeed 权重 20：1 candle→20, 2→15, 3→10
- volume 权重 20：volumeRatio 线性映射到 0-20
- confluence 权重 15：每个通过的过滤器 +3.75（4 个全过 = 15）
- mtfConfluence 权重 15：Phase 2 单 TF 固定为 0（Phase 3 跨周期 scorer 组合时填入）

总分 clamp 到 [0, 100]。

**死猫风险评分**（per D-05, SCORE-02）：

`_calculateDeadCatRisk()` 内部方法，独立维度 0-100：
- 低量反弹（volumeRatio < 0.8）→ +30
- RSI 卡在 50 以下（rsi < 50 且未拐头）→ +25
- 回补不足（recoveryRatio < 0.382）→ +25
- 无共振过滤通过 → +20
总分 clamp 到 [0, 100]。

**evaluate 方法完整流程**：
1. 检查 window 长度是否足够（≥ atrPeriod + dropMaxCandles + recoveryMaxCandles + swingLookback），不足返回 null（warm-up 抵御）
2. 调用 Stage 1 → null 则返回 null
3. 调用 Stage 2 → null 则返回 null
4. 调用 Stage 3 → 获取 confluenceFilters
5. 调用 _calculateScore() → score
6. 调用 _calculateDeadCatRisk() → deadCatRiskScore
7. 构造 ReboundSignal 返回
