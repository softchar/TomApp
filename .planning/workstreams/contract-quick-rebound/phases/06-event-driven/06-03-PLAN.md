创建 `BacktestProvider` (`lib/providers/backtest_provider.dart`)，extends ChangeNotifier：

1. **状态字段**：
   - `BacktestStatus _status = BacktestStatus.idle`，getter `status`。
   - `BacktestConfig _config = BacktestConfig.defaults()`，getter `config`。
   - `BacktestReport? _report`，getter `report`（idle/running 时为 null）。
   - `String? _errorMessage`，getter `errorMessage`。
   - `int _currentFold = 0`，`int _totalFolds = 3`，`int _completedCombos = 0`，`int _totalCombos = 320` —— 进度追踪字段，getter 均公开。
   - `bool _cancelled = false`，用于取消回测运行。

2. **`Future<void> runBacktest()`**：
   - 重入守卫：`if (_status == BacktestStatus.running) { debugPrint('...'); return; }`。
   - 输入验证：`if (_config.startDate.isAfter(_config.endDate) || _config.startDate.isAtSameMomentAs(_config.endDate))` → `_status = BacktestStatus.error; _errorMessage = '起始日期必须早于结束日期'; notifyListeners(); return;`。
   - 日期范围上限：`if (_config.endDate.difference(_config.startDate).inDays > 365)` → error: '回测时间范围最多 365 天'。
   - startDate 下限：`if (_config.startDate.isBefore(DateTime(2020, 1, 1)))` → error: '起始日期不能早于 2020-01-01'。
   - 设置 `_status = BacktestStatus.running; _cancelled = false; notifyListeners()`。
   - 获取标的列表：若 `_config.symbols` 为空，先调用 `await DataImportService().fetchTopSymbols(count: 100)` 填充 `_config.symbols`。获取失败 → error。
   - 数据导入：调用 `DataImportService().importHistoricalData(config: _config)`。若数据为空 → error: '未获取到任何历史 K 线数据'。
   - 引擎运行：创建 `BacktestEngine`、构建 WalkForward `buildParamGrid()`，调用 `walkForward.runWalkForward(...)`，期间更新 `_currentFold/_completedCombos` 进度并 `notifyListeners()`。
   - 完成：`_report = aggregateOutOfSample(...); _status = BacktestStatus.complete; notifyListeners()`。
   - try-catch 包裹全程（on `Exception catch (e)`）：status → error，errorMessage = '${e.runtimeType}: ${e.toString()}'（含异常类型名）。
   - **异步但非 compute**：v1 在主 isolate 运行，不额外做 Isolate 并行（延后 v2）。

3. **`void cancelBacktest()`**：设置 `_cancelled = true`。引擎在每次 fold 组合完成后检查 `_cancelled`，若 true 则提前终止。

4. **`void clearResults()`**：`if (_status == BacktestStatus.running) return;`。`_report = null; _errorMessage = null; _status = BacktestStatus.idle; _currentFold = 0; _completedCombos = 0; notifyListeners()`。

5. **`void updateConfig(BacktestConfig newConfig)`**：只在 `_status != BacktestStatus.running` 时允许修改。`_config = newConfig; notifyListeners()`。
