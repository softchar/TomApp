**文件 1: lib/models/alert_level.dart**

定义 AlertLevel 枚举：high（响铃+vibrate）、medium（横幅）、low（仅看板）。

定义 AlertDecision 不可变数据类，字段：
- symbol: String（交易对，如 "BTCUSDT"）
- level: AlertLevel（分级）

**文件 2: lib/services/rebound/alert_throttler.dart**

类名 AlertThrottler。私有成员：
- Map\&lt;String, DateTime\&gt; _lastAlertTime：per-symbol 最后推送时间（内存，非持久化）
- int _todayCount：当日已推送计数
- String _todayDate：缓存的日期字符串（yyyy-MM-dd 格式）
- 静态常量 int cooldownHours = 4
- 静态常量 int dailyLimit = 20

公开方法 AlertDecision? evaluate(ReboundSignal signal, {required Map\&lt;String, bool\&gt; timeframeToggles, required int highThreshold, required int medThreshold})：

Step 1 — 分级 (_classify)：基于 signal.score 和 signal.deadCatRiskScore 与阈值比较。
- high: score >= highThreshold 且 deadCatRiskScore < 50
- medium: score >= medThreshold（不满足 high 条件时）
- low: 其余情况。low 立即返回 null（仅看板）

Step 2 — 周期开关：timeframeToggles[signal.timeframe] == false → 返回 null

Step 3 — 冷却检查：_lastAlertTime[signal.symbol] 存在且 now.difference(last).inHours < cooldownHours → 返回 null

Step 4 — 跨日重置：_todayDate != today → _todayDate=today, _todayCount=0

Step 5 — 日上限：_todayCount >= dailyLimit → 返回 null

Step 6 — 通过：记录 _lastAlertTime[signal.symbol]=now, _todayCount++。构造 AlertDecision(symbol, level, signal, coalescedTimeframes: [signal.timeframe]) 并返回。

分级辅助方法 AlertLevel _classify(int score, int deadCatRiskScore, int highTh, int medTh)：纯函数，按上述规则返回。

reset() 方法：清空 _lastAlertTime、_todayCount=0、_todayDate=''。供 ReboundAlertService.stop() 调用。

每日重置通过 DateTime.now().toIso8601String().substring(0, 10) 判断跨日。

关键设计决策（per RESEARCH.md Common Pitfalls）：
- Pitfall 1 规避：冷却键仅用 signal.symbol（不含 TF），所以 _lastAlertTime['BTCUSDT'] 而非 _lastAlertTime['BTCUSDT-15m']
- Pitfall 2 规避：跨日重置逻辑在 evaluate() 入口执行
- Pitfall 5 规避：归并逻辑 (Step 4) 在本 phase 单周期下恒跳过（monitoredTimeframes.length==1），但架构预留 coalesceWindowMinutes=60 窗口参数和 _pendingCoalesce Map\&lt;String, List\&lt;AlertCandidate\&gt;\&gt;（本次不实现归并逻辑本身，仅在注释中标注扩展点）
- 不导入 dart:async、flutter、shared_preferences、flutter_local_notifications——AlertThrottler 是纯 Dart 同步逻辑

在 alert_throttler.dart 文件头注释中说明：@visibleForTesting 标记 _resetDailyForTesting(String date) 方法供测试注入假日期，覆盖跨日场景。
