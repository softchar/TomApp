# Phase 6 -- UI Design Contract

> Visual and interaction contract for the BacktestScreen (回测验证) UI component.
> Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> This is a single-screen Flutter UI contract for a primarily backend/engine phase.
> The BacktestScreen consumes a BacktestProvider (ChangeNotifier) and displays
> backtest results produced by the event-driven engine.

Destructive (`#EF4444`) reserved for:
- Negative PnL text
- Max drawdown stat card value

## Interaction Flow

### State Machine

```
                    ┌─────────┐
                    │  idle   │  ← Initial state. Config form visible, results hidden.
                    └────┬────┘
                         │ User taps "开始回测"
                         ▼
                    ┌─────────┐
                    │ running │  ← Config form disabled, progress indicator shown.
                    └────┬────┘     Results section hidden. Cancel button available.
                         │
               ┌─────────┴─────────┐
               ▼                   ▼
          ┌─────────┐        ┌─────────┐
          │complete │        │  error  │  ← Error message + retry button.
          └────┬────┘        └────┬────┘     Config form re-enabled.
               │                  │
               │    User taps     │
               │    "重试"        │
               │    ──────────────┘
               │
               │ User taps "清除回测结果"
               ▼
          ┌─────────┐
          │  idle   │  (back to start)
          └─────────┘
```

### Detailed Interactions

| Trigger | Behavior |
|---------|----------|
| Tap "开始回测" | Provider calls `run()`, state → running. Button replaced by disabled state with CircularProgressIndicator. Config fields become read-only. |
| Tap date field | Opens system `showDatePicker()`. Range constrained: start ≥ 2020-01-01, end ≤ today, start < end. |
| Backtest completes | Provider state → complete. Results section animates in (implicitly, via conditional rendering). Scroll to results section. |
| Tap "清除回测结果" | `showDialog` with destructive confirmation. On confirm: Provider clears all results, state → idle. |
| Tap trade list column header | Toggle sort (asc/desc). Visual indicator: arrow icon (↑/↓) on active sort column. |
| Tap trade list row | `Navigator.push` to KlineScreen with `symbol`, `highlightStartMs` (entry timestamp), `highlightEndMs` (exit timestamp). KlineScreen already supports highlight params. |
| Tap help icon (AppBar) | `showDialog` with explanation of each stat card metric and disclosure meaning. |
| Backtest in progress, user navigates away | Provider continues running. On return, `Consumer` rebuilds with current state. No data loss. |
| Backtest in progress, user taps back | Show confirmation dialog: "回测正在运行中，确定要离开吗？" (prevent accidental interruption). |

## Edge States

| State | Visual | User Action |
|-------|--------|-------------|
| **idle** (no data) | Config card visible + empty state illustration area with "尚未运行回测" copy. Results and disclosures hidden. | Configure and start. |
| **running** | Config card disabled. Centered `CircularProgressIndicator` with progress text ("正在运行回测...（1/3 fold，45/320 组合）"). Cancel button below. | Wait or cancel. |
| **complete** | Full report visible: equity curve → stat grid → trade list → disclosures → disclaimer. Config card collapsed to summary (date range + param count). "清除回测结果" text button at bottom. | Review, drill-down, or clear. |
| **error** | Config card re-enabled. Error card with `Icons.error_outline` (AppColors.destructive), error message, and "重试" OutlinedButton. | Fix issue and retry. |
| **complete (0 trades)** | Report shows zero values in stat cards, "无符合条件的交易记录" in trade list. Disclosures still shown (important: even with zero trades, the methodology is transparent). | Review configuration, adjust parameters. |

## Accessibility Requirements

| Requirement | Implementation |
|-------------|---------------|
| Touch targets | All tappable elements (buttons, trade rows, sort headers) minimum 48px height |
| Color independence | Equity curve lines differentiated by BOTH color AND dash pattern (zero-cost: solid, with-cost: dashed). Stat card values use +/- prefix in addition to color. |
| Text scaling | Body uses `bodyMedium` (14px) as base; all text scales with system font size settings (no hardcoded sizes outside AppTextStyles) |
| Screen reader | All stat cards have `Semantics` widget with combined label+value. Trade list rows announce full trade details. Chart has written summary as `Semantics` label. |
| Contrast | All text on `AppColors.surface` (#1E293B) uses `AppColors.textPrimary` (#F8FAFC) -- contrast ratio ~13:1 (exceeds WCAG AAA 7:1) |

## Chart Specification (Equity Curve)

| Property | Value |
|----------|-------|
| Library | `fl_chart` ^1.2.0 (already in pubspec.yaml, used by ReboundDashboardScreen) |
| Chart type | `LineChart` with two `LineChartBarData` |
