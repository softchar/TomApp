    **B) ReboundAlertService 编排器**：

    在 `lib/services/rebound/rebound_alert_service.dart` 创建 `ReboundAlertService`。

    **构造函数注入：**
    - `ReboundKlineStreamService _streamService`
    - `ReboundDetector _detector`（Phase 2 纯函数实例，注入 TechnicalIndicators）
    - `ReboundScoreProvider _provider`
    - `ReboundParams _params`（业务先验起步值）
    - `ExchangeInfoService _exchangeInfoService`

    **核心管线（per D-04）：**
    ```
    _onClosedKline(ClosedKline c):
      1. if (!c.isClosed) return;  // k.x 二次验证（per D-03）
      2. if (_streamService.isWarmingUp(c.symbol, c.tf)) return;
      3. window = _streamService.windowOf(c.symbol, c.tf);
      4. signal = _detector.evaluate(window, _params, symbol: c.symbol, timeframe: c.tf);
      5. _signalsBySymbol[c.symbol][c.tf] = signal;
      6. mtfScore = ReboundConfluenceScorer.scoreMultiTimeframe(_signalsBySymbol[c.symbol]);
      7. if (signal != null):
         - enrichedSignal = signal.copyWith(score: (signal.score + mtfScore).clamp(0, 100));
         - _provider.upsert(c.symbol, c.tf, enrichedSignal);
       else:
         - _provider.upsert(c.symbol, c.tf, null);
    ```

    **Watchlist churn（per D-09）：**
    - `Timer.periodic(Duration(hours: 1), _refreshWatchlist)`
    - `_refreshWatchlist()`:
      1. 调用 `_exchangeInfoService.refreshSymbols()` 获取当前活跃合约列表
      2. 对比当前订阅的 symbols
      3. 移除下架合约：`_streamService.removeSymbols(delisted)` + `_provider.removeSymbol(delisted)`
      4. 添加新上线合约：`_streamService.addSymbols(newSymbols)`（触发 warm-up）
    - 注意：`removeSymbols` 和 `addSymbols` 是 ReboundKlineStreamService 需要新增的方法（Task 1 中已隐含）

    **生命周期：**
    - `Future<void> start(List<String> symbols)` — 启动 WS 连接 + 订阅 closedKlineStream
    - `Future<void> stop()` — 停止 WS + 取消订阅 + 清空 provider
    - `StreamSubscription? _closedKlineSub`
